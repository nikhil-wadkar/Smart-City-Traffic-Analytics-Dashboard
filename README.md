# 🚦 Smart City Traffic Analytics Dashboard | Python + Power BI

## 📌 Project Overview

This project analyzes over **2.8 million road accident records** from the United States to identify accident trends, environmental influences, and high-risk locations.

Using **Python** for data preparation and **Power BI** for visualization, the dashboard helps uncover valuable insights that can support traffic safety improvements and data-driven decision-making.

---

## 🎯 Objectives

- Analyze accident distribution across states and cities
- Identify accident hotspots
- Understand weather and environmental impacts
- Discover peak accident hours
- Build an interactive dashboard for decision-makers

# 🔍 Key Insights

- Most accidents occur during clear weather conditions.
- Reduced visibility significantly increases accident frequency.
- Peak accident hours align with morning and evening rush hours.
- Urban areas experience substantially higher accident counts.
- Temperature and weather conditions influence accident severity.
